# lukac.fr

Nouvelle version du site officiel de Luka C, développée en local avec XAMPP et versionnée sur GitHub.

## Lancer en local

1. Cloner le dépôt dans `C:\xampp\htdocs\lukac`
2. Démarrer Apache dans XAMPP
3. Ouvrir `http://localhost/lukac/`

## Structure

- `index.html` : page d'accueil
- `assets/css/styles.css` : direction artistique et responsive
- `assets/js/main.js` : menu mobile et animations
- `assets/img/logo-lukac.png` : logo officiel Luka C

## Logo

Déposer le logo officiel dans :

`assets/img/logo-lukac.png`

Le site prévoit un fallback texte si l'image n'est pas encore présente.
